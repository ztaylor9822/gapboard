# Gap Board

Weekly NFL, college football and NBA projections against the DraftKings line, with posted plays and a public record.

Static site: `index.html` is the whole board (data embedded). `data/` holds the same week's board and every tracked pick, with highlighted plays flagged, for grading.

Deployed with Cloudflare Pages: no build command, output directory `/`. Every push to `main` goes live.
